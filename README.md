# DevSecOps AI Platform

Production-oriented AI platform demonstrating modern DevSecOps, Kubernetes, GitOps, observability and LLM engineering practices.

## Project Goals

This project demonstrates how to design, secure, deploy and operate an AI-powered application on Kubernetes.

The platform focuses on:

- Cloud-native architecture
- Kubernetes
- Infrastructure as Code
- CI/CD
- DevSecOps
- GitOps
- LLM and RAG
- Observability
- Security
- Production readiness

## Security

Security is treated as a first-class concern throughout the platform.

The project will include:

- SAST
- SCA
- Container image scanning
- Secret scanning
- IaC security scanning
- SBOM
- Image signing
- Kubernetes security policies
- RBAC
- Network policies
- Secrets management
